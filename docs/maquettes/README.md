# Maquettes

Les ouvrir avant de toucher au rendu. Aucune n'est à jour sur tout : ce
tableau dit ce que chacune montre encore de juste. `CLAUDE.md` (« Apparence »)
l'emporte sur elles.

| Dossier | Ce que c'est | Fait référence pour |
|---|---|---|
| `origine/` | Les maquettes de départ du projet | les fenêtres, leurs espacements, l'anneau d'accent, le rangement |
| `dock/` | Le dock, le tiroir, le centre de contrôle, le mixeur | le dock (lecture : `docs/conception/dock.md`) |
| `verre/` | Captures de la refonte « verre liquide », clair et sombre, et ses images d'inspiration (`references/`) | les matières : verre, liserés, flou, ombres |

## `origine/`

1. `1-quatre-usages.png` : les quatre situations du tableau des usages, sur
   les trois écrans.
2. `2-dev-web-clair.png` : le dev web avec IA, en thème clair.
3. `3-soiree-raid-sombre.png` : le raid MMO, en thème sombre.
4. `4-ranger-une-fenetre.png` : ranger une fenêtre en la glissant vers un
   emplacement.
5. `5-appli-inhabituelle.png` : une appli jamais rangée, qui s'ouvre en
   flottant avec sa barre de rangement (retirée depuis : la fenêtre
   reste flottante, sans barre).
6. `6-gros-plan-fenetres.png` : barre de titre, anneau d'accent, espacement.
7. `7-gros-plan-lanceur-notifications.png` : le lanceur et les notifications
   pendant un jeu.

**Ce qui n'y est plus vrai** : les barres latérales et le lanceur (remplacés
par le dock), les onglets et les boutons dans la barre de titre (remplacés
par les capsules, `docs/conception/capsules.md`), le bouton ⇄ « échanger
avec le centre », le menu de disposition (les dispositions se choisissent
dans « Paramètres » : plein écran, 2 colonnes, 3 colonnes, maître / esclave),
« Tout envoyer vers l'écran… » et « Mémoriser cette disposition ».

Les notifications de la maquette 7 (qui évitent l'écran du jeu) restent une
piste pour la phase 5 (`docs/phase-5.md`, étape 1), pas une décision.
